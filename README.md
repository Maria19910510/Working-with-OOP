# Проект: Модель товаров и категорий

Данный проект реализует базовые классы для моделирования товара и категории в магазине или складе, их тестирование и расширение.

## Задача

Создать две основные модели:

- `Product` — товар, содержащий такие свойства, как название, описание, цена и количество.
- `Category` — категория товаров, содержащая название, описание, список товаров и счетчики общего числа категорий и товаров.

---

## Основные функциональности

### 1. Создание классов и их атрибутов

- `Product`:
  - `name` (str): Название товара.
  - `description` (str): Описание товара.
  - `price` (float): Цена товара, допускающая наличие копеек.
  - `quantity` (int): Количество в наличии, целое число.

- `Category`:
  - `name` (str): Название категории.
  - `description` (str): Описание категории.
  - `products` (list): Список объектов `Product`, входящих в категорию.
  - Общие атрибуты класса:
    - `category_count` (int): Количество созданных категорий.
    - `product_count` (int): Общее число созданных товаров.

### 2. Инициализация объектов

- В конструкторе (`__init__`) каждого класса параметры передаются при создании объекта и автоматически сохраняются.
- `Category` отслеживает количество созданных категорий и товаров с помощью атрибутов класса, которые увеличиваются при создании каждого нового объекта.

### 3. Тестирование

- Используйте `pytest` для написания тестов, проверяющих:
  - корректность инициализации объектов `Category` и `Product`
  - правильность подсчёта количества категорий и товаров
  - корректность работы списков и атрибутов
